# Game Replay Pro

专为移动端玩家打造的低功耗后台即时回录工具。无需提前手动开启全量录屏占用大量空间，应用在后台维护轻量循环缓存，遇到游戏高光操作时点击悬浮球、通知栏磁贴或音量快捷键，即可一键保存刚刚发生的前 N 秒游戏画面与原声。

---

## 1. 核心功能

- **循环缓存回录**：后台仅保留最近设定时长（如 15 秒至 120 秒）的视频切片，自动覆盖旧片段，不占多余存储。
- **一键无感保存**：支持悬浮球、控制中心快捷开关（Quick Settings Tile）、音量组合键触发，后台极速合成 MP4，不打断游戏对局。
- **系统内录与混音**：支持 Android 10+ 游戏内部原声采集，并可同时开启麦克风解说录制。
- **内置高清播放器**：支持应用内预览、进度拖拽、双击快进快退、横竖屏自适应全屏回放及一键导出至系统相册。

---

## 2. 使用方法

1. 打开应用，按提示授予通知、悬浮窗和录音权限。
2. 在首页打开「游戏回录」开关（或下拉手机控制中心点击「游戏回录」磁贴）并允许屏幕录制。
3. 进入游戏对局，出现精彩操作后点击屏幕边缘的悬浮球，即可保存刚才的精彩片段。
4. 返回应用「视频库」查看、全屏播放、分享或导出视频到手机相册。

## 3. 自行打包 APK 指南

从 GitHub 下载或克隆本项目后，可通过以下任一方式自行打包生成安装包（輸出路径均为 `app/build/outputs/apk/debug/app-debug.apk`）：

### 方式一：使用项目内置脚本一键打包（推荐）
需本地安装 JDK 21 与 Android SDK（API 36）。
- **Windows**：双击运行根目录下的 `build_apk.bat`，或在终端执行：
  ```bat
  .\build_apk.bat
  ```
- **macOS / Linux**：在终端执行：
  ```bash
  chmod +x build_apk.sh && ./build_apk.sh
  ```

### 方式二：使用 Gradle 命令行打包
- **Windows**：`.\gradlew.bat assembleDebug`
- **macOS / Linux**：`./gradlew assembleDebug`

### 方式三：使用 Android Studio 打包
1. 用 Android Studio 打开项目根目录，等待 Gradle Sync 自动完成（项目会自动还原 `debug.keystore` 签名配置）。
2. 点击顶部菜单 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** 即可生成安装包。

### 方式四：GitHub Actions 免环境云端打包
若电脑未安装开发环境，将仓库 Fork 到自己的 GitHub 后，进入 **Actions** 页面选择 **Android APK Build**，点击 **Run workflow**，构建完成后在页面底部 **Artifacts** 下载打包好的 APK。

## 4. 在电脑端运行方式

1. **安卓手游模拟器运行（推荐）**：在电脑安装 MuMu 模拟器 12、雷电模拟器 9 或蓝叠模拟器，将打包好的 `app-debug.apk` 直接拖入模拟器窗口安装即可运行。
2. **Android Studio 模拟器运行**：在 Android Studio 的 Device Manager 中创建并启动 Android 13+ 虚拟设备，点击顶部 **Run 'app'** 运行。
3. **真机连接电脑投屏运行**：手机开启 USB 调试连接电脑，执行 `adb install -r app/build/outputs/apk/debug/app-debug.apk` 安装到手机，配合 `scrcpy` 投屏软件在电脑端显示与操作。
